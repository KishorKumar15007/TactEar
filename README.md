# TactEar

TactEar is an early software prototype for a future wearable tactical acoustic-awareness system.

## Current Prototype

This repository is being prepared for a software baseline covering audio classification, simulated binaural localization, and structured event output. Those capabilities are not implemented yet.

## Hardware Status

Physical headset hardware is not yet integrated. Current directional-audio development uses simulated stereo input with known ground truth.

## Current Development Scope

This milestone intentionally excludes hardware integration, a shared suppression/classification encoder, SOP retrieval, a local LLM, and a UI.
